
# 📝 Work Planner – To-Do Web App

A minimal and intuitive web application to manage your daily tasks and boost productivity. Add, update, delete, and track your to-dos with ease!

## 🚀 Features

- ✅ Add new tasks
- 🖊️ Edit existing tasks
- ❌ Delete tasks
- 📋 View your daily to-do list
- 💾 Data persistence using browser local storage (optional)
- 💡 Clean and responsive user interface

## 🧠 How It Works

1. User enters a task in the input field.
2. Task is displayed in the list with options to mark as done or delete.
3. Updates reflect instantly without page reload.
4. *(Optional)* Tasks are stored locally for persistence.
